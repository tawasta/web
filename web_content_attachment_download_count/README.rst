==================================
Attachment Download Count Tracking
==================================

* Tracks how many times attachmetns have been accessed
* Incrementing happens when attachment is accessed via 
  /web/content

Configuration
=============
* None needed

Usage
=====
* Download an attachment
* See the incremented count in Knowledge treeview.
