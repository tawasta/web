================================
Web: Hide Action Menus for Group
================================
* Hide Print and Action menus in backend for group members

Configuration
=============
* Add the relevant users to the new "Cannot see Print and Action Dropdown Menus"
  group

Usage
=====
* Open any form/list/etc view as a member of the group. The dropdown menus
  do not show up
