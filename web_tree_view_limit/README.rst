==============================
Change General Tree-view limit
==============================
* Allows setting record limit for all treeviews at once


Configuration
=============
* Go to Settings -> General Settings and change
  "General Tree view limit" value to limit the records shown
  on all tree views.
* A queue job will keep the limits up to date for
  upcoming views

Usage
=====
* Install this module from Apps.

Known issues / Roadmap
======================
* There are no known issues with this module.
