=================================
Report layout standard formatting
=================================

Alter report layout to be similar to SFS 2487 standard formatting.
Please note that this layout is only similar to the standard for readability, but does not conform to it.
The formatting has no official relation to the standard.

Configuration
=============
* To hide header set variable "hide_header" to true before calling
  web.external_layout
* To hide foooter set variable "hide_footer" to true before calling
  web.external_layout
