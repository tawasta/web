===========================================
Web Report: C5-friendly Address Positioning
===========================================

* Adds an alternative address block for the report layouts, where the
  recipient information is on the left side, so that it aligns with the
  window of a C5 letter

Configuration
=============
* None needed

Usage
=====
* Does nothing by itself: the reports that should use the alternative block
  request it in their own modules, e.g.
  account_report_invoice_c5_letter_friendly_positioning and
  stock_report_delivery_slip_c5_letter_friendly_positioning
